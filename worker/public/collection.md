# Meme Lab — Collection

Canonical URL: https://memes.significanthobbies.com/collection

The collection is the full browsable and searchable catalogue behind Meme Lab's recommendations: 3,000 references made of 1,805 named meme templates and 1,195 usage-backed reaction GIFs.

## What each record carries

- A short **message** — the sentiment the meme expresses.
- A **relational pattern** — the social dynamic it captures.
- An **example context** and a **near-miss context** describing when it fits and when it does not.
- Tags, media type (image or GIF), preview and source URLs, provenance, evidence state, and rights state.

Each reference has a stable page at `https://memes.significanthobbies.com/memes/{id}`; append `.md` or send `Accept: text/markdown` for a Markdown version of the same record.

## Provenance

- 1,195 GIFs come from the GIF Reply research dataset of 1.56 million observed conversation-to-GIF replies, each with at least 108 observed uses.
- Static templates are named memes with corrected metadata; a checked-in canonical coverage manifest tracks recognizable gaps.
